Vocab App đã được nâng cấp!

Ứng dụng học từ vựng đã được nâng cấp lên phiên bản Full-stack Web App có thể deploy, tích hợp cơ sở dữ liệu SQLite để lưu trữ và sử dụng AI (Gemini) để phân loại từ vựng tự động theo chuyên ngành và hoàn cảnh sử dụng.

Bước 1: Cài đặt thư viện dependencies
npm install
Bước 2: Khởi chạy Server ứng dụng
npm start
Bước 3: Truy cập Web App bằng Trình duyệt
Truy cập đường dẫn: http://localhost:3000
Mở Ứng Dụng (Localhost:3000)
