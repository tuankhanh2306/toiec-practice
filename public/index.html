Sao Lưu & Khôi Phục Dữ Liệu

Bảo vệ tiến trình học tập của bạn:
  • Xuất sao lưu (Export): Tải toàn bộ chủ đề, từ vựng, cấp độ thuộc bài và chuỗi streak ra file JSON an toàn trên máy tính của bạn.
  • Khôi phục (Import Backup): Nạp lại dữ liệu từ file sao lưu JSON trước đó nếu bạn đổi máy tính hoặc trình duyệt.

Nhập Tài Liệu & Phân Tích AI

Hỗ trợ phân tích & phân loại chuyên sâu:
  • Tải lên file: Word (.docx), PDF (.pdf), Text (.txt), CSV (.csv), hoặc JSON (.json).
  • Nếu có **Gemini API Key**, AI sẽ tự động phân tích toàn bộ văn bản tài liệu, trích xuất các từ vựng chính, và tự động sắp xếp theo chuyên ngành và hoàn cảnh sử dụng thực tế.
  • Nếu chưa có API Key, hệ thống sẽ phân tích ngoại tuyến từ thô (yêu cầu định dạng từ - nghĩa - ví dụ).
